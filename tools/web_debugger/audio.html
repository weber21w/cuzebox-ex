Native DAC cadence OCR2A cycle spacing

Cadence uses the cycle timestamps already stored in armed DAC history. It can expose late or missing DAC updates without adding another timing hook. Large cycle gaps are stronger underrun/discontinuity evidence than waveform shape alone.

Clipping attribution

Native DAC rail means OCR2A itself reached 0 or 255. Host rail means the final SDL output reached its device endpoint after resampling/filtering/monitor effects/reverb/master volume.

Attribution is by observed stage, not by logical Uzebox mixer channel. If host rails occur without native DAC rails in the armed evidence window, host-side processing is the likely added contributor. Repeated consecutive rail samples are stronger clipping evidence than a single endpoint sample.

Capture behavior

The source oscilloscope needs no explicit arming. Host-output capture is opt-in and is automatically disarmed when this page unloads on browsers that deliver the unload beacon.
