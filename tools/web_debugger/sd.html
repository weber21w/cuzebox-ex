History and break conditions share one SD-byte gate. With history and all triggers off, the tracer does nothing; FLAG_SD_TRACE=0 removes the gate and ring entirely. Command breakpoints stop after the R1 response is produced, so argument, result, state transition and sector are all available.


Automated timing stress runner API-driven; no emulation hot-path code
python3 tools/sd_stress_runner.py --frames 900 --conformance --threshold read_wait_bytes=0:128 --expect-mem SRAM:0x10F:==:1
The runner can sweep one or more SD timing fields, binary-search the largest passing latency, export CSV/JSON results, and restore the original SD timing/trace state afterward. --conformance also fails a case on reconstructed protocol errors even if the ROM completes its frame budget. See documentation/web-debugger.md for options.


Deterministic interaction record / replay exact card-visible SPI stream; explicitly armed
Recording captures card-visible BYTE_START (MISO sample), BYTE_END (MOSI delivery), CS and reset events with exact relative cycle timestamps, preserving even a CS edge during an in-flight byte. Replay restores the captured initial SD state, returns the recorded MISO stream, validates MOSI/CS/reset ordering and timing, and bypasses VFAT; any divergence requests a debugger stop.


Deterministic fault injection explicitly armed; up to 8 independent rules
SlotStateFaultValueCMDSectorModeFiredLast cycle
R1_DELAY and TOKEN_DELAY values are extra SPI bytes; BUSY_EXTEND is extra milliseconds; R1_BITS/REJECT use an R1 bit mask. CMD_CRC and DATA_CRC accept value 1. ONCE disarms the rule after its first matching injection; PERSIST remains armed. Rules are evaluated only in the SD protocol phase they can affect.
