Raster breakpoint

PORTC-event capture is off by default because the beam view already contains a complete per-cycle PORTC trace; enable it when a VCD needs individual PORTC writes.

Deterministic SD interaction record / replay

Recording captures card-visible BYTE_START (MISO sample), BYTE_END (MOSI delivery), CS and reset events with exact relative cycle timestamps, preserving even a CS edge during an in-flight byte. Replay restores the captured initial SD state, returns the recorded MISO stream, validates MOSI/CS/reset ordering and timing, and bypasses VFAT; any divergence requests a debugger stop.

Fault injection

Read-only state inspection has no tracing cost. SD history/break conditions share one gate at the SD-byte boundary; Step Into/Over/Out refreshes both status and any protocol event generated by that instruction.
