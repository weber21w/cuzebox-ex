UART transmit-complete timer fix - 2026-10-29

Active source: C:/cuzebox-dev-green-led/cuzebox-ex-main
This is a local source fix and Windows build. No GitHub push was performed.
The parent checkout contains unrelated changes; the patch includes only this fix.

cu_avr.c owns USART TX completion timing independently of an optional peer.
It uses configured frame lengths instead of the old fixed 1,304-clock delay.
The existing usr0_tran/usr0_end and UCSR0A fields hold the scheduling state;
the saved CPU blob layout was not changed. TXC is sticky and acknowledged by
W1C/ISR entry. Mask-only changes and TXC acknowledgment preserve pending RX.

Changes are in cu_avr.c, interrupt_regression.c, serial.md, and one reset
dependency stub in resident_bootloader_regression.c.
